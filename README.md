Inventory Monitoring and Automated Reorder Reporting

Project Overview

This project uses Python to monitor inventory levels, estimate product demand, identify low-stock products, and generate automated reorder recommendations.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- CSV

Key Analysis

1. Data cleaning and preprocessing
2. Average daily demand calculation
3. Days of inventory remaining
4. Stock status classification
5. Suggested reorder quantity
6. Low-stock reporting
7. Inventory visualization

Project Deliverables

- Inventory Summary Report
- Reorder Report
- Stock Status Chart

Business Objective

To help retail companies monitor stock levels and make better inventory replenishment decisions.
